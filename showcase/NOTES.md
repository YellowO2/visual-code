# Showcase notes

Material for a page or video about visual-code. Screenshots are here; anything
else can be regenerated by running the tool on the commits below.

## The story in pictures

1. `01-panoramic-before-no-wiring.jpg` — panoramic-da3 as it was: the tool finds no wiring, only folders.
2. `02-panoramic-first-wires-15-inputs.jpg` — first wiring: 15 inputs on the left wall, files passed through disk.
3. `03-checks-warnings.jpg` — the checker lists what breaks the rules, with file and line.
4. `04-elk-layout.jpg` — right-angle wires routed around boxes.
5. `05-machine-inside-machine.jpg` — ViewExtractor opened: a machine inside a machine.
6. `06-panoramic-after-2-in-2-out.jpg` — panoramic-da3 after: panoramas and settings in, point clouds and DA3's verdict out.
7. `07-streetview-top-level.jpg` — streetview-to-3d's whole system on one line.
8. `08-streetview-postprocess-opened.jpg` — one of its machines opened.
9. `09-streetview-toolbox.jpg` — the shared tools in their own strip, with no wires.
10. `10-downward-flow-with-shelf.jpg` — flowing down the page; a shelf (`clean/`) as a dashed box inside a machine.
11. `11-ui-and-engine-side-by-side.jpg` — after "parts don't call parts": the UI and the engine as two machines side by side, values entering at the top.
12. `12-react-flow-reconstruct-opened.jpg` — drawn with React Flow and ELK: the page fills the screen, and opening a machine (here `reconstruct`) glides its boxes into place while the view follows it.
13. `13-job-runs-handed-engine.jpg` — after "a button only triggers its job": the Reconstruct job opened, its `corridor` and `settings` wired into the engine's own ports and `folder` coming back.
14. `14-two-operations.jpg` — after "a machine offers one operation": the engine is a shelf of two machines, `gather_panoramas` and `build_scene`; each UI job calls its own endpoint, shown with what it takes.

## Numbers

- panoramic-da3: inputs 15 -> 2, outputs 6 -> 2; slices stay in memory instead of a JPEG round trip through disk.
- streetview-to-3d: checker warnings 194 -> 53 after the first pass -> 0 after the world/ pass; tests 84 -> 100, all passing; world files byte-identical on a real Stockholm map run.
- A fresh agent given only the skill restructured panoramic-da3 close to the hand-made result.
